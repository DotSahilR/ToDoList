# 📌 ToDoList 

A full-stack **To-Do List Application** built with **React + TypeScript (Frontend)** and **Node.js + TypeScript (Backend)**.

This app allows users to create, update, and delete tasks using a RESTful API.

---

# 🚀 Tech Stack

## 🖥️ Frontend
- React
- TypeScript
- CSS (Responsive Design)
- Axios (API calls)

## 🔧 Backend
- Node.js
- TypeScript
- Express.js
- REST API Architecture

# ⚙️ Features

## ✅ Core Features
- Add new tasks
- View all tasks
- Mark tasks as complete/incomplete
- Delete tasks
- Responsive UI (Mobile + Desktop)
- Authentication (Signup/Login)
- Task filtering
- Sorting
- Search functionality

---

# 🖥️ Application Pages

## 🏠 Home Page
- Displays all tasks
- Shows task name and status
- Mark task as complete/incomplete
- Delete tasks

## ➕ Add Task Page
- Input field for task name
- Status selection (Complete / Incomplete)

# 🛠️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/DotSahilR/ToDoList.git
cd ToDoList
```

---

## 2️⃣ Backend Setup

```bash
cd server
npm install
npm run dev
```

---

## 3️⃣ Frontend Setup

Open a new terminal:

```bash
cd client
npm install
npm run dev
```
